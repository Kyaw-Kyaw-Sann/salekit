# SaleKit

SaleKit is a simple and responsive point-of-sale practice project built with React, TypeScript, Tailwind CSS, and localStorage.

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Lucide React
- React Hot Toast

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Project Status

SaleKit is being built step by step as a React learning and practice project.
